## Enable Sponsors (owner only)

1. Sign in as **TwiztedFX** in a browser (not as a bot).
2. Open [https://github.com/sponsors](https://github.com/sponsors) or [https://github.com/sponsors/TwiztedFX](https://github.com/sponsors/TwiztedFX).
3. Choose **Get sponsored** (personal account).
4. Fill the profile: who you are (Pragmex Agentics / this CLI), what money is for (maintenance, not a fake “enterprise license”).
5. Add at least one **tier** (example: $5/month “thanks”, $25/month “priority bug look”). Keep copy plain.
6. Connect **Stripe** when GitHub asks (tax country = yours). Complete identity if prompted.
7. Submit for GitHub’s review. Wait for email. Do not pay for boosts.
8. When approved, confirm [https://github.com/sponsors/TwiztedFX](https://github.com/sponsors/TwiztedFX) loads.
9. This repo already has `.github/FUNDING.yml` pointing at `TwiztedFX`. After approval, GitHub shows **Sponsor** on the repo.

- Put bank details, Stripe keys, or tax IDs in this git repo.
- Require Sponsors to use the MIT tool.
- Contact employers or buy ads to fill the sponsor page.
